# Session Runtime Architecture Decisions

Status: DECISION INDEX (DOMAIN-SCOPED)

These records preserve the historical architecture rationale for Session Runtime. They are not current accepted truth.

**Split (2026-09-28):** these 25 records were originally part of the `GAME-ADR-*` family, created while Game Management, Session Runtime, and Game Language shared one "Game" bounded context. Now that Game Management and Session Runtime are independent bounded contexts (`docs/decisions/architecture/ADR-0014-management-session-domain-split.md`), the records whose rationale is Session-Runtime-lifecycle-specific moved here, into their own independent-sequence family. Each record below keeps a `Legacy ID: GAME-ADR-NNNN` header line recording its immediate prior identifier; `docs/decisions/LEGACY_ADR_ID_MAP.md` records the full mapping (including, for the records originally migrated on 2026-09-07, the older `ADR-NNNN` identifier before that) so every old reference remains resolvable. A handful of records stayed at `game/docs/decisions/` instead — foundational/shared ones, the retirement decision itself, and ones about Game Language's own internal engine/sandbox mechanics, which currently live physically inside `game/` — see that index's own note for which and why.

Current accepted truth for Session Runtime is owned by `session/README.md` (and, where applicable, `session/CURRENT_STATE.md`, `session/docs/DATA_MODEL.md`, `session/docs/FLOWS.md`, and package-local docs referenced from the Knowledge Map). Agents should not read every Session ADR by default; load an individual record only when the rationale/history behind a current rule is actually needed.

This index is the Session Runtime decision family under the repository-wide routing model described in `docs/decisions/README.md` and `docs/decisions/INDEX.md`. Naming: `SESSION-ADR-NNNN`, with its own independent sequence, starting after this split at `SESSION-ADR-0026`.
