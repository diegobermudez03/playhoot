# Product Roadmap

This is an outcome-oriented product roadmap. It is not an implementation task tracker. Ordering can change through accepted product decisions.

## Outcome Milestones

### Reliable Playable Game / Session Foundation

- Players can participate in rule-driven multiplayer sessions.
- Sessions can progress, complete, and remain trustworthy enough for real users.
- Generated games can be validated for safe, consistent play.

### Complete End-to-End Multiplayer Experience

- A host can choose a game, start a session, invite players, run the game, and complete the session.
- Players can join, interact, receive feedback, and see the final outcome.

### Creator Identity and Game Lifecycle

- Creators can sign in, create games, revise them, and publish stable versions.
- Published game versions remain controlled as creator changes continue.

### AI-Assisted Creation and Preview / Refinement

- Creators can express game intent conversationally.
- Playhoot can produce a playable draft, support preview/testing, and apply focused refinements.

### Templates, Publishing, and Public Discovery

- Templates provide useful starting points without limiting expressivity.
- Public games can be discovered/searchable.
- Users can create or play sessions from appropriate public games.

### Initial Public Launch Readiness

- The initial public product delivers enough value for external users, with education/classroom use as the primary initial focus.
- Launch readiness includes the required creator, host, public content, and player loops.

### Post-Launch Growth / Monetization Experiments

- Explore audience expansion beyond the initial education emphasis.
- Evaluate monetization approaches through future product decisions and experiments.
